# Enterprise Dashboard

## Overview

This project provides the structural foundation for an accessible enterprise dashboard using semantic HTML5 and WCAG 2.1 accessibility principles.

## Project Structure

- `index.html` - Main dashboard page
- `dashboard.html` - Reports page
- `users.html` - User management page
- `components/` - Reusable HTML components
- `css/` - Stylesheets
- `README.md` - Project documentation

## Semantic HTML

The project uses semantic HTML5 elements including:

- header
- nav
- main
- section
- article
- aside
- footer

## Accessibility

The project includes:

- Proper form labels
- Accessible navigation
- Keyboard-friendly controls
- ARIA labels where required
- Form validation attributes
- Accessible data tables
- Accessible dialog structure
- Visible keyboard focus

## Validation

HTML files are validated using the W3C HTML Validator.

Target:

0 HTML syntax errors.

## Local Setup

1. Download or clone the repository.
2. Open the project in VS Code.
3. Open `index.html` in a browser.
4. Navigate between Dashboard, Reports, and Users.
5. Test the pages using keyboard navigation.

## First Feature Slice

The first feature slice is the accessible user search and management flow:

User → Dashboard → Search/User Form → Validation → User Data → Results
